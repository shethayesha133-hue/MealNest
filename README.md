# MealNest – Meal Discovery Website

## About the Project
MealNest is a web-based meal discovery and recipe management application. It helps users explore meals, search recipes, view ingredients and cooking instructions, and save their favorite meals.

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## Features
- Search for meals
- Explore meals by category
- View recipe details and ingredients
- Add and edit recipes
- Save favorite meals
- View cooking instructions and recipe videos
- Contact page

## How to Run the Project
1. Install Python.
2. Download or clone this repository.
3. Install the required packages using `pip install -r requirements.txt`.
4. Run the application using `python app.py`.
5. Open the local URL displayed in the terminal in your browser.
